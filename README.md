## 🌐 How to Deploy to View by Any Third Party

### Method 1: Netlify Drop (Instant 1-Minute Live Link — Recommended)
This is the fastest, foolproof way to get a permanent live link with zero setup:
1. Open [app.netlify.com/drop](https://app.netlify.com/drop) in your web browser.
2. Drag and drop the whole `portfoliowebsite` folder from your desktop onto the browser window.
3. Within 10 seconds, Netlify gives you a public HTTPS URL (e.g., `https://jose-ashmitha-qa.netlify.app`).
4. Anyone worldwide (recruiters, clients, third parties) can open this link on their mobile phones, tablets, or computers!

### Method 2: GitHub Pages (Free 24/7 Hosting on your GitHub)
1. Go to your GitHub account: [https://github.com/new](https://github.com/new) and create a repository named **`portfolio`** (Public).
2. Inside your `portfoliowebsite` folder, double-click **`deploy-to-github.bat`**.
3. It will automatically stage, commit, and push all files to `https://github.com/joseashmitha/portfolio.git`.
4. On GitHub, go to **Settings > Pages**.
5. Under **Build and deployment**, set Source to **Deploy from a branch**, select branch **`main`** and **`/ (root)`**, then click **Save**.
6. Your portfolio will be live 24/7 at:
   ```
   https://joseashmitha.github.io/portfolio/
   ```

### Method 3: Instant Live Sharing Tunnel (Immediate Live Link via terminal)
1. Double-click `share-portfolio.bat` in this folder.
2. It starts the local server and generates an instant secure public HTTPS tunnel URL (`https://xxxx.lhr.life`).
3. Send this link to anyone to view right now while your computer is on.
